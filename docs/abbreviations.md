# Abbreviations

Common abbreviations used across agentgateway documentation, policies, and explanations.

| Abbreviation | Full form | Notes |
|--------------|-----------|-------|
| A2A | Agent-to-Agent | Protocol for agent-to-agent communication |
| AGW | Agent Gateway | The open-source agentgateway proxy |
| API | Application Programming Interface | |
| AS | Authorization Server | External OAuth/OIDC server that issues tokens |
| CEL | Common Expression Language | Expression language used for authorization and policies |
| CI/CD | Continuous Integration / Continuous Deployment | GitHub Actions workflows |
| CRD | Custom Resource Definition | Kubernetes resources such as AgentgatewayPolicy |
| ExtProc | External Processing | Envoy-style external processing filter |
| HITL | Human-in-the-Loop | Human approval or confirmation step |
| JWT | JSON Web Token | Token format used for authentication |
| JWKS | JSON Web Key Set | Public keys used to validate JWTs |
| LLM | Large Language Model | Models such as GPT, Claude, Gemini |
| MCP | Model Context Protocol | Protocol for connecting agents to tools and data |
| OBO | On-Behalf-Of | Microsoft Entra token exchange flow |
| OAuth | Open Authorization | Authorization framework |
| OIDC | OpenID Connect | Identity layer on top of OAuth 2.0 |
| OSS | Open Source Software | Open-source agentgateway (vs Enterprise) |
| RBAC | Role-Based Access Control | Authorization model |
| RFC | Request for Comments | IETF standards (e.g. RFC 8693 token exchange) |
| STS | Security Token Service | Component that issues or exchanges tokens (Enterprise feature) |
| TLS | Transport Layer Security | Encryption for connections |
| UI | User Interface | |
| URL | Uniform Resource Locator | |

These abbreviations appear throughout the policies, testdata, and documentation for MCP, A2A, and LLM traffic.
